## 🚀 Featured Work

- **Chargemaster Data Processing Pipeline** — Medallion (Bronze/Silver/Gold) pipeline on Databricks processing hospital pricing files from thousands of sources, with automated file discovery (Selenium + Azure OpenAI) and ML-based schema mapping
- **Sam Data Feed** — SQL views + PySpark pipeline generating structured, drug-level nested JSON from Azure SQL data, feeding a production **RxDx RAG chatbot** via Unity Catalog
- **HealthPlan Data Processing** — 8-stage PySpark pipeline flattening and joining large nested JSON (up to 30–50 GB) into a Gold-layer dataset, with skew-aware batching
- **Azure DQX Data Quality Framework** — 20+ column-level validation rules across 3+ billion records, with a good/quarantine split for auditability
- **RAG Container App Deployment** — Zero-downtime Azure Container Apps memory migration (32 GB → 16 GB) via a two-phase Bicep rollout
